### EMPRESA: Projeto próprio

### DESCRIÇÃO CURTA: O presente projeto caracteriza-se como uma análise de dados que mescla elementos da pesquisa causal-comparativa e descritiva, com delineamento ex-post facto. A análise foi feita utilizando um corte transversal dos dados de 2022 da Tabela FIPE, obtido no Kaggle. Foi realizada a separação das marcas e a análise de valor médio de mercado dos veículos de acordo com motorização, tipo de câmbio e combustível. A ideia é mostrar como esses fatores impactam no valor de venda de veículos no Brasil, segregando o resultado entre veículos de marcas de luxo e de marcas populares.
