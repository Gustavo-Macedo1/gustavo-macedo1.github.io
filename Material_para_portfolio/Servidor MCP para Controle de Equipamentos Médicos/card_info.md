### TÍTULO: Servidor MCP para Controle de Equipamentos Médicos

### EMPRESA: Instituto Hardware BR (Centro Integrado de Inteligência Artificial)

### DESCRIÇÃO CURTA: Este repositório é uma prova-de-conceito (POC) para o controle de equipamentos médicos através de um servidor MCP (Model-Context-Protocol) simples feito com FastMCP para expor tools que interagem com uma base MySQL. O projeto usa Llama Index para construir agentes que consomem essas tools e Ollama como provedor local de LLM (modelo local). O projeto final (usado pela empresa após aprovação da POC) é privado (não tenho o direito de compartilhar o repositório), e consiste em um app mobile (iOS e Android) de controle de dispositivo médico real por voz, acionando tools no hardware (na linguagem C) com wakeword, DeepGram, Groq, FastAPI e outras ferramentas.
